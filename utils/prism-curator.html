prism · growth curator

⚙ what this is

Prism's six original scenes (Sphere, Scroll, Theater, Orbiter, Leaf, Orrery) are its frozen seed — grown once, ambient only, never editable from here. This tool is for genuinely new writing: one entry here becomes one new branch grown onto the crystal the next time the site builds, and — unlike the seed — it's clickable, opening the standard read panel.

How it works: entries you add below are saved only in this browser's localStorage — nothing is sent anywhere, and nothing is written to disk automatically. When you're ready, hit "copy as JS" and paste the result into src/text/prismEntries.js, inside the prismEntries array, then rebuild the site. That's a deliberate choice, not a shortcut: this page is a plain static file with no server behind it, same as the rest of the site, so it has no way to write to the repo itself — a copy-paste hand-off matches the one other tool like this the project already has (utils/nebula-curator.html, retired but same pattern: local staging area, "copy as JS," pasted in by hand).

Blank lines split the text into separate paragraphs — same convention scrollPieces.js and poems.js already use.
